# בוקי — QA ושחרור פיילוט 2026-09-10

## מה משתחרר
- **דשבורד מורה:** ליד כל מועדון מוצגים בזמן אמת מספר התלמידים וסך דקות הקריאה, מסכום `memberships.cachedStats.totalMinutes`. תלמידים עם `status: left` אינם נספרים. כשל טעינה אינו מוצג כ־0. פח המחיקה הוקטן.
- **שמירת קריאה:** שלושת מסלולי השמירה הפעילים מקבלים מזהה השלמה קבוע. מסך הצלחה מוצג רק אחרי אישור שמירה; ניסיון חוזר עם אותו מזהה אינו מוסיף דקות פעמיים. במועדון, עדכון `cachedStats`, רשומת session וארנק קיים נכתבים באותה Firestore transaction.
- **תוכן:** הקטלוג המפורסם נסרק ותיקוני ניקוד, כתיב, דקדוק וניסוח מוחלים בזמן הריצה לפי `story id` ועמוד. מזהי הסיפורים והמבנה נשארים ללא שינוי. דוגמאות: `גִּיחֵךְ`, `הָאֲרִי יָצָא לַחוֹפְשִׁי`, `סִינְדֶּרֶלָה`, `חִזְרִי לִפְנֵי חֲצוֹת`.
- **מצב בלי ניקוד:** ההמרה מפרידה בין ניקוד המקור לבין כתיב מלא לקריאה ללא ניקוד. לדוגמה `הַבַּרְוָזוֹן הַמְכֹעָר` מוצג `הברווזון המכוער`, ואילו `פְּעָמִים` נשאר `פעמים` ולא נהפך ל־`פעמיים`.

## מבנה השחרור
`initial-setup.js` מוסיף loader אחד: `pilot-loader-2026-09-10.js`. ה-loader טוען מודולים קטנים ומבודדים, בסדר קבוע:
1. שמירת קריאה אטומית.
2. overrides למסכי סיום הקריאה.
3. מיפויי מצב ללא ניקוד והלוגיקה שלהם.
4. ארבע חבילות תיקוני תוכן + apply.
5. דקות מועדון חיות בדשבורד המורה.

כך אין החלפה של קובצי הליבה הגדולים, אין שינוי ב־Firebase Security Rules, וניתן לבצע rollback באמצעות commit יחיד.

## בדיקות אוטומטיות שעברו על מועמד השחרור
- קטלוג runtime על בסיס קובצי הייצור הנוכחיים + מודולי השחרור: **61 סיפורים / 370 עמודים**. נבדקו גם סיפורי החגים שנטענים מאוחר יותר.
- נבדק שאין סימני ניקוד שנשארים במצב ללא ניקוד, ונבדקו רגרסיות מרכזיות: `גיחך הארי`, `הארי יצא לחופשי`, `סינדרלה`, `חזרי לפני חצות`, `עשר פעמים`, `הברווזון המכוער`.
- שמירה אטומית: שמירה ראשונה, retry עם אותו completion id, כשל transaction ללא הוספת דקות, מניעת בעלות שגויה על כרטיס, מסלול קורא אישי ומסלול legacy — עברו.
- דשבורד מורה: סכימת דקות משני תלמידים פעילים, אי־הכללת תלמיד שעזב, `aria-live` ופח מחיקה מוקטן — עברו.
- כל מודולי ה־JavaScript החדשים ו־`initial-setup.js` עברו `node --check`.

## מה לא שונה
- אין שינוי ב־Firebase Security Rules במסגרת השחרור הזה.
- מנגנון אישורי הפרטיות/החתימות נשאר מושהה בהתאם להחלטת הפיילוט.
- אין שינוי במזהי תלמידים, מזהי סיפורים או נתוני קריאה קיימים.
- אין חסימת סיפורים למורה; ספריית המורה נשארת לעיון בתכנים.
